# Code of conduct

This project is the git repository and the issues and pull requests on it. The technical argument can be blunt. The person on the other side of it is not the target.

## Expected

- Criticise the change, the measurement, or the document.
- Say what you ran and what it printed when you claim a result.
- Assume the other person has not seen your terminal.

## Not accepted

- Insults, harassment, or sexual attention aimed at a person.
- Publishing someone's private information.
- Dismissing a measured bug because the tone of the report was inconvenient.

## Reporting

Open a [GitHub issue](https://github.com/chy3xyz/mem3/issues) when the report can be public. Use a [private security advisory](https://github.com/chy3xyz/mem3/security/advisories/new) when it cannot. Maintainers of `chy3xyz/mem3` handle both. A report that is mostly a conduct problem is not answered with a patch discussion.

Maintainers may edit or hide a comment, lock a thread, or block an account. They will say which item above was crossed.
