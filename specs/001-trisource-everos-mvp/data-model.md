# Data Model: TriSource-EverOS MVP

**Branch**: `001-trisource-everos-mvp` | **Spec**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md)

**Purpose**: Formal type definitions, storage layouts, and valid-state invariants for all persistent entities.

---

## Conventions

- **Zig 0.17 idioms**: explicit `Allocator` injection, no hidden globals, `std.Io` runtime passed explicitly to async functions.
- **Serialization**: `comptime`-generated, no runtime reflection. All persistent types have `pub comptime serialized_size: usize`.
- **Endianness**: little-endian on disk (x86_64, aarch64). `std.mem.nativeToLittle` for read, `nativeFromLittle` for write.
- **IDs**: monotonic `u64` assigned by the relevant allocator (`next_memcell_id`, `next_hyperedge_id`, `next_goal_id`).
- **Timestamps**: `i64` Unix milliseconds (UTC).

## TS-MemCell

The atomic memory unit. Maps directly to FR-001 and Constitution Principle I.

```zig
pub const MemorySource = enum(u8) {
    matter = 0,    // 物: 感官输入、环境观测、工具返回的原始数据
    form   = 1,    // 象: 推理过程、反思结论、抽象知识
    spirit = 2,    // 性: 工具调用、执行结果、行为轨迹 (性源在论文里 = 目标/意义定向,
                   //      但在 dev.md §2.2.1 里 action 源 = 行为轨迹. 我们用
                   //      论文的 source_tag = 物/象/性 三源本体, 而 dev.md 的
                   //      sensory/cognitive/action 是 GHW 层的具体活动类型.
                   //      详见 AD-0001 调和说明)
};

pub const Fact = struct {
    subject: []const u8,
    predicate: []const u8,
    object: []const u8,
    confidence: f32,         // [0, 1]
    source: []const u8,      // 抽取来源 (e.g., "user_input", "tool_output")

    pub comptime serialized_size: usize = serializer.calculateSize(@This());
};

pub const Foresight = struct {
    description: []const u8,
    valid_from: i64,         // Unix ms
    valid_until: i64,        // Unix ms; i64.max for "always"
    confidence: f32,

    pub comptime serialized_size: usize = serializer.calculateSize(@This());
};

pub const GoalAssociation = struct {
    goal_id: u64,
    relevance: f32,          // [0, 1]
    priority: u8,            // [0, 255]

    pub comptime serialized_size: usize = serializer.calculateSize(@This());
};

pub const Metadata = struct {
    created_at: i64,
    updated_at: i64,
    source_confidence: f32 = 1.0,   // source_tag classification confidence
    emotional_valence: f32 = 0.0,   // [-1, 1]
    location: ?[]const u8 = null,
    access_count: u64 = 0,
    last_accessed_at: i64 = 0,
    coherence_score: f32 = 0.0,     // C_tri
    importance_score: f32 = 0.5,    // α·C + β·G + γ·E
    decay_rate: f32 = 0.01,         // per-day; computed from source_tag
    is_fuzzy: bool = false,         // moved to fuzzy store

    pub comptime serialized_size: usize = serializer.calculateSize(@This());
};

pub const MemCell = struct {
    id: u64,
    source: MemorySource,                 // CONSTITUTIONAL: must be set
    episode: []const u8,                  // 物: 原始 episode 序列化
    atomic_facts: []const Fact,           // 象: 抽取的原子事实
    foresight: []const Foresight,         // 性: 预测性记忆
    goal_associations: []const GoalAssociation, // 性: 目标绑定
    metadata: Metadata,

    pub comptime serialized_size: usize = serializer.calculateSize(@This());
};
```

**Note on source_tag nomenclature**: The `ghw_memory_system.agent.final.md` paper uses `M`/`F`/`S` (物/象/性, ontological) as the source taxonomy, while `dev.md` §2.2.1 uses `sensory`/`cognitive`/`action` (functional, GHW-layer). We unify on the paper's three-source taxonomy as the **canonical** `source_tag` and use `dev.md`'s naming as a *secondary classification* (a `dev.md` "sensory" memory is a `matter` source with a sensory activity subtype stored in `metadata.subtype`). This is documented in `docs/adr/0001-three-source-ontology.md`.

### Valid State Invariants (Constitution Tests)

1. **I1 — source_tag is set**: `cell.source != null` is impossible at the type level (it's an enum), but a runtime check rejects cells with `source_confidence < 0.5` (untrusted classification).
2. **I2 — spirit dimension present**: `cell.foresight.len > 0 || cell.goal_associations.len > 0`. A cell with no foresight and no goal_associations is rejected.
3. **I3 — timestamps monotonic**: `metadata.updated_at >= metadata.created_at`.
4. **I4 — importance ∈ [0, 1]**: `metadata.importance_score >= 0.0 && <= 1.0`.
5. **I5 — episode non-empty**: `cell.episode.len > 0`.

### Storage Layout (on disk)

Binary record:
```
[magic: u32 = 0x4D454D33]              // "MEM3"
[version: u16 = 1]                      // schema version
[cell: MemCell serialized payload]      // comptime-generated bytes
[checksum: u32]                         // xxHash3 of payload
```

For 1M MemCells at ~1KB each, the on-disk `memcells.bin` is ~1GB + index.

## HyperEdge

A typed relation connecting 2+ MemCells. Maps to FR-006.

```zig
pub const EdgeType = enum(u8) {
    causal     = 0,  // 因果: "A caused B"
    temporal   = 1,  // 时序: "A before B"
    associative = 2, // 关联: "A semantically related to B"
    goal       = 3,  // 目标: "A serves goal G"
};

pub const HyperEdge = struct {
    id: u64,
    edge_type: EdgeType,
    nodes: []const u64,            // 2+ MemCell IDs
    weight: f32,                   // [0, 1] — overall relation strength
    source_weights: [3]f32,        // (w_M, w_F, w_S) — three-source weight vector, sum = 1
    confidence: f32,               // [0, 1] — propagation confidence
    created_at: i64,
    metadata: ?[]const u8 = null,  // optional JSON-encoded edge metadata

    pub comptime serialized_size: usize = serializer.calculateSize(@This());
};
```

### Valid State Invariants

1. **E1 — at least 2 nodes**: `edge.nodes.len >= 2`.
2. **E2 — source_weights sum to 1**: `|Σ source_weights - 1.0| < 1e-6`.
3. **E3 — all node IDs valid**: every `edge.nodes[i]` is a `u64` that resolves to a MemCell at lookup time (lazy check; the hypergraph engine does a periodic sweep to drop dangling edges).

### Storage Layout

```
[magic: u32 = 0x48594533]              // "HYE3"
[version: u16 = 1]
[edge: HyperEdge serialized payload]
[checksum: u32]
```

Adjacency index (in-memory only, rebuilt from `hyperedges.bin` at startup):
- `node_to_edges: AutoHashMap(u64, ArrayList(u64))` — for given node, list of edges containing it.
- `edge_to_nodes: AutoHashMap(u64, ArrayList(u64))` — for given edge, list of its nodes (in edge insertion order).

## GoalNode

A node in the Goal Poset. Maps to FR-011.

```zig
pub const GoalStatus = enum(u8) {
    pending    = 0,
    in_progress = 1,
    completed  = 2,
    failed     = 3,
    unrealized = 4,    // Constitution III.C: 标记无关联记忆的目标
    tombstoned = 5,    // 软删除
};

pub const GoalNode = struct {
    id: u64,
    parent_id: ?u64,           // Goal Poset lattice
    name: []const u8,
    description: []const u8,
    status: GoalStatus,
    priority: u8,              // [0, 255]
    deadline: ?i64,            // Unix ms
    created_at: i64,
    updated_at: i64,
    associated_memcell_ids: []const u64,  // 反向索引
    unrealized_at: ?i64 = null, // when marked unrealized

    pub comptime serialized_size: usize = serializer.calculateSize(@This());
};
```

### Goal Poset Properties

The Goal Poset is `(Obj(G), ≤_goal, ⊥, ⊤)`:
- `≤_goal` is the partial order: `g1 ≤_goal g2` iff `g1` is `g2` or an ancestor of `g2`.
- `⊥` (bottom) is a synthetic "root" goal with `id = 0`, no parent.
- `⊤` (top) is a synthetic "all-encompassing" goal with `id = u64.max - 1`, no parent.

These are synthetic — never exposed to the user. They enable lattice queries (e.g., "all goals between X and Y").

### Valid State Invariants

1. **G1 — at most one parent**: `parent_id` is `?u64`, not an array.
2. **G2 — no cycles**: a `DFS(G, from_root)` must terminate; an attempted cycle insert is rejected.
3. **G3 — unrealized has age > 7 days**: a goal marked `unrealized` for > 7 days is a candidate for `tombstoned`.
4. **G4 — at least one associated MemCell OR `status = unrealized`**: Constitution I.C3.

## MemScene

A consolidation-time cluster. Maps to FR-014.

```zig
pub const MemScene = struct {
    id: u64,
    member_ids: []const u64,           // MemCell IDs in this scene
    center_M: []const f32,             // matter centroid (mean of episode embeddings)
    structure_F: []const u64,          // form: common hyperedge sub-structure
    meaning_S: f32,                    // spirit: aggregated importance
    coherence_C: f32,                  // tri-source coherence
    created_at: i64,
    last_consolidated_at: i64,

    pub comptime serialized_size: usize = serializer.calculateSize(@This());
};
```

### MemScene Lifecycle

1. **HAC clustering**: `tests/property/consolidation.zig` simulates clustering 1000 cells with `sim_threshold=0.75` and verifies scene count is `O(sqrt(1000))`.
2. **Knowledge distillation**: if `coherence_C > COHERENCE_THRESHOLD = 0.6`, abstract the scene into a `Knowledge` entry (added to KV index).
3. **Forgetting**: scenes whose `meaning_S < THRESHOLD` are downgraded to "fuzzy" — members move to fuzzy store.

## WAL Record

Append-only log entries for crash recovery. Maps to FR-022.

```zig
pub const WALRecordType = enum(u8) {
    memcell_insert    = 0x01,
    memcell_update    = 0x02,
    hyperedge_add     = 0x03,
    hyperedge_remove  = 0x04,
    goal_create       = 0x10,
    goal_update       = 0x11,
    forget            = 0x20,
    snapshot_marker   = 0xF0,    // boundary marker for incremental recovery
    checksum_marker   = 0xFF,
};

pub const WALRecord = struct {
    record_type: WALRecordType,
    payload: []const u8,            // type-specific serialized data
    timestamp: i64,
    checksum: u32,                  // xxHash3 of (type + payload + timestamp)

    pub comptime serialized_size: usize = serializer.calculateSize(@This());
};
```

### WAL File Format

```
[record 1: 4-byte length prefix | WALRecord bytes]
[record 2: ...]
...
[snapshot_marker: records since last snapshot can be replayed]
[checksum_marker: full file checksum]
```

### Recovery Semantics

On startup:
1. Read the last `snapshot_marker`.
2. Read the last `checksum_marker`. If checksum matches, accept all records after the snapshot.
3. Replay records in order. For each `memcell_insert`, write to memtable + indexes. For each `hyperedge_add`, add to hypergraph. Etc.
4. If checksum mismatches mid-file, stop at the first bad record (best-effort: system starts in degraded mode with a warning).

## Index Maps

### KV Index (id → file offset)

In-memory: `std.AutoHashMap(u64, u64)` mapping `memcell_id` to the byte offset in `memcells.bin`. Rebuilt on startup from a full scan of the bin file (or from the snapshot if present).

### HNSW Index

A layered graph: layer 0 is the dense graph (M_max_0 neighbors per node, default 16); layers 1+ are exponentially sparser (M_max = M, default 8). Top layer has 1 node (the entry point).

Each node stores:
- `vector: []f32` (default 384-dim for the stub embedder)
- `neighbors: [][]u64` (per-layer neighbor lists)
- `level: u8` (max layer for this node)

Insert: search from top, descend, insert at level 0, possibly promote to higher levels with probability `1/M`.

Search: greedy descent from top, then ef-beam at level 0, return TopK by distance.

### Hypergraph Index

Adjacency lists as `ArrayList(u64)` per node, in continuous memory regions. CSR compaction at snapshot time.
