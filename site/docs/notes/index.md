# Design documents

Two long documents ship in the repository. Both are English. Both were written as design, and both say so near the top.

- [Architecture blueprint](engineering-blueprint.md) is `dev.md`. It is not a status report. Sections describe intended architecture. Check `src/` before relying on a paragraph.
- [GHW paper](ghw-paper.md) is `ghw_memory_system.agent.final.md`. The speed-up, the latency, and the Windows and WASM targets in that paper were not measured on this repository. Measured numbers are on the [status](../start/status.md) page and in the [roadmap](../library/roadmap.md).

The build copies those files into this section. Edit the originals in the repository, not a generated HTML page.
