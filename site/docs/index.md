# mem3

mem3 is a memory store for agents. One binary, no database server. macOS and Linux. Version 0.1.0-alpha.

You give it a short text. It tags the text matter, form, or spirit, appends it to a log, and indexes it in memory. A cell needs a foresight or a goal. Forgetting marks a cell, or moves it to the fuzzy store. The record stays in the log.
